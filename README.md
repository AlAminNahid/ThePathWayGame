# Focus Flight ✈️  
*A simple OpenGL/GLUT-based precision game*

## 🎮 Game Overview
In a world of shifting shapes and endless challenges, a plane sets out on a journey of focus and balance.  
Your mission is to guide it through tricky paths, avoiding obstacles that threaten to break its flow.  
Each turn tests your skill and patience, demanding precision and calm control.

## 🛠️ Built With
- **C/C++**
- **OpenGL**
- **GLUT (OpenGL Utility Toolkit)**

## ✨ Features
- Smooth player control mechanics
- Dynamic obstacles to dodge
- Increasing difficulty over time
- Minimal UI focused on gameplay experience

## 🚀 How to Play
| Action | Key |
|--------|-----|
| Move Left | ← Arrow |
| Move Right | → Arrow |
| Pause Game | `P` |
| Quit Game | `Esc` |

Stay focused — one wrong move and you're out!
